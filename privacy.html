プライバシーポリシー

最終更新日：2026年10月27日

1. 対象

本ポリシーは、個人利用目的の Google Apps Script「weight-to-sheets」（以下「本アプリ」）に適用されます。本アプリの利用者は開発者本人のみです。

2. 取得する情報

本アプリは、Google Health API を通じて、承認した Google アカウントの体重・体脂肪率の測定値、測定日時、記録ID、記録元の情報を読み取ります（読み取り専用）。

3. 利用目的

取得した情報は、承認した本人の Google スプレッドシートに記録し、本人が体重の推移を確認する目的にのみ使用します。

4. 保存と第三者提供

取得した情報は、本人の Google アカウント内のスプレッドシートにのみ保存します。開発者が管理する外部サーバーには送信・保存しません。第三者への提供、販売、広告目的での利用は行いません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

6. アクセスの取り消し

承認は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
